# FlexBreak App-Ads.txt Hosting

This folder contains the app-ads.txt file required for AdMob verification.

## Quick Setup with GitHub Pages:

1. Create a new GitHub repository named `flexbreak-app` (or any name)
2. Upload these files to the repository
3. Go to Settings → Pages
4. Enable GitHub Pages from the main branch
5. Your site will be available at: `https://[yourusername].github.io/flexbreak-app/`
6. The app-ads.txt will be at: `https://[yourusername].github.io/flexbreak-app/app-ads.txt`

## Update App Store Listing:

1. Go to App Store Connect
2. Update your app's support URL or marketing URL to the GitHub Pages URL
3. Wait for the update to propagate
4. Then verify in AdMob

## Alternative: Deploy to Vercel (Instant)

1. Sign up at vercel.com (free)
2. Import this folder as a new project
3. Deploy (takes 1 minute)
4. Use the provided domain or add custom domain
5. Update App Store listing with the new URL
